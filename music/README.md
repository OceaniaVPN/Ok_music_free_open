# 🔑 Ключник — локальная музыка

Клади сюда музыкальные файлы. При следующем Cloudflare build они автоматически попадут на сайт как источник **🔑 Ключник**.

## Обложки — автоматически

**JPG рядом с MP3 больше не нужен.** Сборщик сначала пытается достать встроенную обложку непосредственно из метаданных аудиофайла.

Например:

`Коста Лакоста - Черри Леди.mp3`

Если в MP3 внутри записана обложка (ID3/APIC), она автоматически извлекается в `public/music/covers/` и используется на сайте.

Также поддерживаются запасные варианты:
- `Коста Лакоста - Черри Леди.jpg` рядом с файлом;
- `cover.jpg`;
- `folder.jpg`;
- `front.jpg`.

## Название и исполнитель

Лучше всего, если MP3 уже содержит теги:

- Title → название;
- Artist → исполнитель;
- Album → альбом;
- Genre → жанр.

Если тегов нет, используется имя файла:

`Исполнитель - Название.mp3`

## Поддерживаемые аудио

MP3, M4A, OGG, OPUS, WAV, AAC.
