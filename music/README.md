# 🔑 Ключник — локальная музыка

Клади сюда свои музыкальные файлы. При следующем деплое они автоматически попадут на сайт как источник **🔑 Ключник**.

## Имена файлов
Рекомендуемый формат: `Исполнитель - Название.mp3`
Например: `Коста Лакоста - Черри Леди.mp3`
Если имя файла не содержит ` - `, исполнителем будет указан **Ключник**.

## Обложки
Можно положить рядом с треком картинку с тем же именем, например `Коста Лакоста - Черри Леди.jpg`.
Также поддерживаются `cover.jpg`, `folder.jpg` и `front.jpg` внутри папки.
Поддерживаемые аудио: MP3, M4A, OGG, OPUS, WAV, AAC.
